## Version Control for Raspberry Pi Embedded Application

## Aim:

To create a GitHub repository for maintaining different versions of an embedded application.

## Procedure:

1. Open GitHub and sign in.
2. Click New Repository.
3. Enter the repository name as Raspberry-Pi-Embedded-Application.
4. Add a description.
5. Select Public or Private.
6. Click Create Repository.
7. Upload the project files and commit the changes.
8. Create branches to develop and test new features.
9. Merge the tested branches into the main branch.

## Importance:

• Commit History: Tracks all code changes and helps restore previous versions.

• Branches: Allow testing new features without affecting the main code.

• Merging: Combines tested changes into the main project.

• Backup: Stores source code safely online.

• Collaboration: Allows multiple developers to work on the same project.

## Example Repository Structure:

Raspberry-Pi-Embedded-Application/

├── main.py

├── sensor.py

├── motor_control.py

├── README.md

└── Branches:
    ├── main
    ├── sensor-testing
    └── motor-control

## Result:

GitHub repository is created successfully to maintain, track, test, and manage different versions of a Raspberry Pi embedded application.
